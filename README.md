**TravelEase** is a modern travel management website where users can easily browse different vehicles or travel models, make bookings, and share their experiences. It provides a seamless and responsive experience for travelers.

---

## ✨ Features

- 🧭 **Dynamic Travel Models:** Browse and select from a variety of cars and travel models.
- 🔐 **Authentication System:** Login and registration powered by Firebase, including Google Sign-In.
- 💾 **Database Integration:** Store and retrieve data using MongoDB.
- 💬 **Responsive UI:** Fully responsive design with React and Tailwind CSS.
- 🚗 **Private Routes:** Secure pages accessible only to logged-in users.
- 🌐 **Deployment:** Client on Netlify, Server on Vercel.

## 📦 Main Dependencies Used

The project uses the following libraries and packages:

- **React** (`react`, `react-dom`)
- **Tailwind CSS** (`tailwindcss`, `@tailwindcss/vite`)
- **Firebase** (`firebase`)
- **React Router** (`react-router`, `react-router-dom`)
- **React Icons** (`react-icons`, `lucide-react`)
- **Styled Components** (`styled-components`)
- **Animation & Motion Libraries** (`framer-motion`, `@react-spring/web`, `motion`, `aos`)
- **Date Handling** (`date-fns`)
- **UI Components** (`daisyui`, `swiper`)
- **Notifications & Alerts** (`react-hot-toast`, `react-toastify`, `sweetalert2`)

> All these dependencies are installed via `npm install`.
